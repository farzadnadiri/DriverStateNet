# Reference values

`tri_published_wilcoxon.csv`: behavioural validation table of Gideon et al., *A Simulator Dataset
to Support the Study of Impaired Driving* (arXiv 2507.02867v1), transcribed from the arXiv HTML
version on 27 Oct 2026. Columns are mean difference (condition − baseline, participant means) and
Wilcoxon p-value for intoxication (n = 20), cognitive distraction (n = 52), and both (n = 20).
The paper has no gaze-pitch row and reports no effect sizes. **Check against the published
PDF/ITSC version before citing.**
